# LvDetector_WWW_2015
Source Code for the WWW 2015 paper "Automatic Detection of Information Leakage Vulnerabilities in Browser Extensions" by Rui Zhao, Chuan Yue, Qing Yi.
If you use this source code in research publications, please cite the corresponding research paper:

        "Automatic Detection of Information Leakage Vulnerabilities in Browser Extensions."
        By Rui Zhao, Chuan Yue, and Qing Yi. In proceedings of the International World Wide Web Conference (WWW), 2015.

The research paper can be accssed at https://dl.acm.org/doi/10.1145/2736277.2741134

The source code was developed by Rui Zhao with the advise and collaboration from Chuan Yue and Qing Yi over 11 years ago.
We release the code after 11 years because some researchers recently asked us if we can share it.
Note that the authors did not further maintain or update the code, so please do not contact them for any questions.
June 6th, 2026.
